
## 一、统计术语

基期、现期
==🟣增加值：今年创造了多少==，直接替换为GDP做题，因为 在 GDP 核算里：`GDP = 各行业增加值之和`
==🟣增长量：比去年多了多少==： 现期- 基期 = 现期 * r / （1 + r）
					≈ 现期 * r * (1-r) =   现期 * r -  现期 * r * r  在 |r| <10%可以快速估算
增长率，又称增幅、增速 = 增量 / 基期 = 现期 / 基期 -1 
降幅 =  1 - 现期 / 基期 = （基期 - 现期）/ 基期

年均增长量 =  （现值 - 基值）/ 间隔年份
变化量：增量的绝对值

#### 份数思想：
增长量快速计算公式：假如增长率百分比为 |r| = 1/N，常用于 |r| 超过10%：
增长量 = 现期量 / （1 + N）
减少量 = 现期量 / （N - 1）
==🔴简化计算将百分比减少/增加n%时，最终的结果可以近似相同的减少/增加n%。==
慎用：r为负数且过大（一般超过30%）

|r| 在5%以内，且选项差距较大时，估算可用：增长量 ≈ 现期量 * r

## 增速的累积与拆分
不直观看到谁是总的谁是部分，画一条小学图形

#### 1、将同一个主体的两项增长累计为一次完整的增长
累计增速 = r1 + r2 + r1 * r2

#### 2、已知累计增长和一个部分增长，求另一个部分增长
假设累计增长为 r1，一个部分增长为 r2
则另一部分增速 = （r1 - r2）/ (1 + r2)

#### 3、比值变化关系
环比的同比变化

环比倍数 = 当月r1 / 上月r2
当月同比增速 > 上月同比增速，则当月环比倍数同比提高，环比增速同比提高
当月同比增速 < 上月同比增速，则当月环比倍数同比下降，环比增速同比下降
当月同比增速 = 上月同比增速，则当月环比倍数同比不变，环比增速同比不变

## 1、基期比值
已知现期和同比增长，快速求基期的比值（两个基期求比值一般都是指求环比）
==🔴给增速低的一方补正平均数增长率==
第一个式子是指 r1 <  r2，r是指同比增速，r1、r2是相比于谁是分子谁是分母来看的，而不是左边比右边，所以说给增速低的一方补正增长率
第二个式子是指 r1 > r2
