## 一、统计术语

基期、现期
==🟣增加值：今年创造了多少==，直接替换为GDP做题，因为 在 GDP 核算里：`GDP = 各行业增加值之和`
==🟣增长量：比去年多了多少==： 现期- 基期 = 现期 * r / （1 + r）
					≈ 现期 * r * (1-r) =   现期 * r -  现期 * r * r  在 |r| <10%可以快速估算
增长率，又称增幅、增速 = 增量 / 基期 = 现期 / 基期 -1 
降幅 =  1 - 现期 / 基期 = （基期 - 现期）/ 基期

年均增长量 =  （现值 - 基值）/ 间隔年份
变化量：增量的绝对值

比重：占总体的百分比

百分点：两个百分数相减得到的差值，比如 10% 与9% 相差一个百分点

顺差 = 出口额 − 进口额
逆差 = 进口额 − 出口额

## 化除为乘

适用范围：增速比较小的情况
求基期时，已知  增长率 在5%以内，除号改成乘法，分母的加减互换
求增长量时，使用 ==🟡现期 * r== 计算时，得到的结果要注意消除误差，比如结果要减去 ==🟡结果 * r==的误差值

![[Pasted image 20261103145832.png]]

#### 份数思想：
增长量快速计算公式：假如增长率百分比为 |r| = 1/N，常用于 |r| 超过10%：
增长量 = 现期量 / （1 + N）
减少量 = 现期量 / （N - 1）
==🔴简化计算将百分比减少/增加n%时，最终的结果可以近似相同的减少/增加n%。==
慎用：r为负数且过大（一般超过30%）

|r| 在5%以内，且选项差距较大时，估算可用：增长量 ≈ 现期量 * r
