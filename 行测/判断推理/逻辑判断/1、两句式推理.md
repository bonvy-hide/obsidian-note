### 充分条件、必要条件知识补充

充分条件：p → q，有p就够，可以理解为 p 是 q 的子集
必要条件：p → q，q是p的必要条件，没 q 不行，q是p的全集
逆否命题：¬p → ¬q，即 q → p


### 一、两句式推理的结构特征

定义：论据和论点均包含推理。
论据和结论有重复内容，前一半重复或者后一半重复，所以分两种情况。

#### 1、补全逻辑的支持和假设
a、
论据：A -> B
结论：A -> C
正确选项：只要B就C；只有C才B

或者

b、
论据：A -> C
结论：B -> C
此时的解题结构为（见视频五的末尾）： B -> A + A -> C = B -> C
正确选项：只要B就A；只有A才B

【总结】 ：先看重复的是前面还是后面
（1）二句式推理中，论据和结论一般均包含推理并且有重复信息（前一半重 复或者后一半重复）。 
（2）二句式推理中，论据要参与推理，正确选项需要包含论据中的关键信息， 而不能仅仅针对结论支持或者反驳（二句式推理中优先反驳推理而不是反驳）。 
（3）论据是实验数据，统计信息，背景介绍等等，跟结论没有明显的主语（前 一半）或者影响效果（后一半）重复时。只需要关注结论的推理。

### 3、指出相同的支持，指出不同的削弱

题型：
没有质变是否等于量变
论据：儿童时有到青年仍有
论点：治疗无效
解题：青年可能好了但没完全好，所以削弱无效的结论
![[Pasted image 20261117113616.png|510]]

【方法提炼：遇到“XX 是无效的”这类结论】
1. **先分清“没有达到某个指标”和“没有任何效果”**。出题人最爱用“患病率”“复发率”“投诉量”这类指标来冒充“效果”。
2. **优先找直接说“有效果/有好处”的选项**，它构成对论点的直接反驳，力度最强。
3. **警惕“只描述现象差异、不提原因”的选项**（如 C）：这类选项看起来像证据，实际上留着一个“自然发生”的解释，力度立刻减半。
