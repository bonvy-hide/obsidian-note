
| 特征   | 由因推果  <br>(Causal Prediction) | 由果推因  <br>(Causal Explanation)       |
| ---- | ----------------------------- | ------------------------------------ |
| 推理方向 | 原因结果                         | 结果原因                                |
| 核心目的 | 预测可能发生的结果                     | 解释已发生结果的原因                           |
| 思维方向 | 顺向（从过去/现在指向未来）                | 逆向（从现在指向过去）                          |
| 确定性  | 理论上更确定（理想情况下）                 | 通常不确定（多因一果，需排  <br>除其他可能）            |
| 典型问题 | “如果...发生，会怎样？”                | “为什么“”...会发生？是什  <br>么导致了？”  <br>... |
| 应用举例 | 科学预测、工程设计、政策效  <br>果预估        | 事故调查、医疗诊断、故障排  <br>除、历史研究            |

### 由因推果
#### 题型一、推导链不是简单的因直接到 -》果

   C            →       机制1        →       机制2        →        E
（原因）              （中间环节）          （中间环节）          （结果）

   削弱选项答案可以是以下的，力度从上到小：
   ①C不存在/量不足   
   ②机制1不成立      
   ③机制2不成立      
   ④有反向作用    
   ⑤E另有来源

![[Pasted image 20261118162256.png|428]]


#### 一、建立联系

【加强】
1）A 带来的一个因素、作用、影响、导致了 B。 
A与B相关
核心关注点：
+ 主体A是什么
+ 导致的效果B是什么


2）说 A 是 B 的重要因素，重要标准、重要组成部分。 
B 的好坏，取决于 A 这个标准。

【削弱】
1）指出无关


#### 二、直接引入他因

![[Pasted image 20261120104643.png|558]]

题型三：削弱时：对特定情况的削弱并无法对结论进行削弱。例如C选项
![[Pasted image 20261120162654.png|517]]


#### 2、引入他因-直接说利弊

加强：利大于弊
削弱：弊大于利

#### 3、引入他因-两者相比

例如 A比B好
【支持】说A好或者说B不好
【削弱】当然是两者相反


#### 4、引入他因-利弊相权

【底层推理结构】
1、因为A有优点，所以我们要执行A
2、A会带来一个好结果。
+ 支持：如果没有带来更大的弊端
+ 削弱：如果能带来更大的弊端

注：从严谨的逻辑角度讲，带来的必须是更大的利，或者更大的弊。 但是从考官设计选项的角度，只要指出有反向的因素即可，不必须明确体现 “更大”。

#### 5、引入他因-做了也白做

题干会引入一个原因，和一个正常的情况，预期达到的效果

【反驳】引入一个其他的原因，阻碍或者抵消了论据中原因的影响，就说明 做了也白做，无法达到结论预期的效果。

#### 6 引入他因- 量变不等于质变

1.量变不等于质变。==🔴（如果论据是量变，结论是质变，那么要考虑质变的标准）== 
2.系统是有容错性的，只有超过了系统的承载限度，才会开始改变。 
所以并不意味着任何程度的量变都一定会带来结果的改变。

#### 7、直接引入他因

【直接针对结论引入他因】
削弱：所有一句式推理（针对结论）的反驳，本质上都是直接引入一个让结论推理 不成立的他因。 
1.关注主体范围，主体范围要一致。 
2.关注结论产生的效果，效果的范围要明确。（不是非常宽泛的好与坏） 
3.做过一道题，就要深刻理解引入他因的底层逻辑关系，这样碰到一样的题 目时就可以举一反三迅速秒杀。

#### 8、引入其他角度的他因

之前的引入他因，都是站在A的角度，比如：
【做了也白做】从 A 的角度，指出阻碍 A，或者弱化 A 因素的效果，导致结 果不成立。 
【利弊相权】从 A 的角度，指出 A 虽然带来一个优点，但是同时带来更大的 缺点，从而导致结果不成立。 

==🔴【引入其他角度他因】==引入一个 C 的角度，同样也能影响 B，带来了其他角 度的影响因素，从而导致结果成立（支持）或者不成立（削弱）。

#### 9、前真后假

前真后假：削弱
前假后真：也是削弱，假如选项中没有前真后假，它可以做备选
前假后假：支持


#### 10、引入他因-直接举例子（陈述事实）

题量较少
【特征】并不从逻辑的角度去分析原因或者因果关系，直接举出一个符合结论的事实进行支持

#### 11、直接反驳结论、论据
真题数不多
