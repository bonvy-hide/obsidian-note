
| 特征   | 由因推果  <br>(Causal Prediction) | 由果推因  <br>(Causal Explanation)       |
| ---- | ----------------------------- | ------------------------------------ |
| 推理方向 | 原因结果                         | 结果原因                                |
| 核心目的 | 预测可能发生的结果                     | 解释已发生结果的原因                           |
| 思维方向 | 顺向（从过去/现在指向未来）                | 逆向（从现在指向过去）                          |
| 确定性  | 理论上更确定（理想情况下）                 | 通常不确定（多因一果，需排  <br>除其他可能）            |
| 典型问题 | “如果...发生，会怎样？”                | “为什么“”...会发生？是什  <br>么导致了？”  <br>... |
| 应用举例 | 科学预测、工程设计、政策效  <br>果预估        | 事故调查、医疗诊断、故障排  <br>除、历史研究            |
| 削弱方式 | 引入一个让结果不成立的他因                 | 引入一个让结果成立的他因                         |

【由因推果的选项陷阱】：
由其他不同主体导致结果成立的他因，不算削弱选项

### 一、由因推果
#### 题型一、推导链不是简单的因直接到 -》果

   C            →       机制1        →       机制2        →        E
（原因）              （中间环节）          （中间环节）          （结果）

   削弱选项答案可以是以下的，力度从上到小：
   ①C不存在/量不足   
   ②机制1不成立      
   ③机制2不成立      
   ④有反向作用    
   ⑤E另有来源
