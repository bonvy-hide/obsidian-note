## 一、语句选择题

【提问方式】
作者接下来最有可能讲的是...
这是一篇文章的==🔴开头/引言==，这篇文章最可能介绍的是....

注意：如果问“摘要”，则为中心理解题。

1、解题方法
+ 通读全文，重点关注文段最后谈论的核心话题
+ 话题保持一致与连贯，对比选项确定答案

2、干扰项
+ 已经详细论述/讨论过的内容
+ 与最后谈论过的核心话题不一致、不连贯

3、答案特征
+ 文段提及的核心话题+ 文段未论述的新内容

## 二、语句填空题

【提问方式】
填入划线部分最恰当的一项/一句是....

解题方法： 
注重衔接得当： 
（1）横线为分句，优先注重句内衔接 
（2）横线为完整语句，注重句子之间的关联

1、横线在结尾
+ 总结全文
+ 提出对策

2、横线在开头
+ 概括后文
+ 话题引入

3、横线在中间
+ 承上启下，可能仅承上，也可能仅启下

## 三、语句排序题

【提问方式】
将以上/下几个句子重新排列，语序正确的是？

【解题方法】
（1）根据选项提示对比确定首尾句，尾句往往总结/对策
（2）确定捆绑/确定顺序，两句强关联、或者有明显顺序，比如时间顺序等
（3）验证，一步到位得出的答案可能要验证下，大部分都无法给你一步到位

#### 1、确定首尾句

1、首句特征：下定义的适合做首句
例句：
……就是/……是指/所谓……/指的是

2、非首句特征
+ 指代不清的指代词：这、那、他、其、该、此、当时等
+ 关联词的后半部分单独出现：但是。。。/因此。。。
+ 明确的举例标志：正如。。。/总书记指出

3、尾句特征
+ 总结性尾句：因此、所以、看来、于是、这
+ 对策性尾句：应该、需要

#### 2、确定捆绑

1、指代词捆绑
+ 这、那、他、其、该、此、这些、那些、他们、它们

2、关联词捆绑
+ 转折：前后话题相关且语义相反，然而、但
+ 并列：前后话题语义相关

#### 3、确定顺序

1、行文逻辑
观点+ 解释说明
提出疑问+ 回答问题
问题+ 对策

2、日常逻辑
+ 时间先后顺序
+ 行动先后、事情发展的脉络
