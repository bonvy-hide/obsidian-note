
【提问方式】 
这段文字主要 / 旨在 / 重在 / 意在 / 想要说明（论述、强调）的是……  
这段文字的主旨 / 主题 / 观点是…… 
对这段文字概括最恰当的一项是……  
这段文字表达了作者…… 
从这段文字中我们可以看出作者的意图 / 态度是……

## 直接确定重点

1、存在转折关系的关联词
典型标志词：
虽然……但是…… 
尽管……可是…… 
……不过…… 
……然而…… 
……却…… 
其实 / 事实上 / 实际上

解题方法：
==🔴转折之后的重点==

2、内容层面的主题词
定义：文段围绕的核心话题，文段要围绕其展开

判断方法：
+ 每句话都围绕相同话题
+ 中心句围绕的核心话题，一般前有引入或后有说明

解题方法：
==🔴正确选项肯定包含主题词，主题词不局限于一个==

![[Pasted image 20261110144333.png|432]]


题型积累
+ 从。。。到。。。的转变，把。。。转化为。。。（此类句式的重点肯定是后边呀）

### 二、因果关系

1、典型格式
因为……所以…… 
由于……因此……
所以、因此、因而、故而、故
于是、可见、看来
在这种情况下、可以说、换言之等

2、解题方法
+ 结论是重点
+ 当结论句的后面仍然有语句
	+ 之后的语句是进一步说明，此时中心句仍然是结论句
	+ 之后又出现并列、因果、转折、对策等，需进一步分析

### 三、必要条件格式

1、典型格式
只有。。。才。。。

2、解题方法
+ 必要条件是重点


3、对策语句
对策标志词：
	1、应该、应当、应、需要、要、必须 + 做法
	2、通过 / 采取……手段 / 途径 / 措施 / 方式 / 方法 / 渠道，才能……
	3、前提、基础、保障
	4、负有……的义务 /……的必由之路 /……的法门之一 / 势在必行 / 要领在于……

对策类的主题词一般就是==🔴对策和对象==

还存在三种出题可能：==🔴反面提对策、文段无对策，并列关系==

### 四、并列关系

1、文段特征
+ 包含并列关联词及标点，如：此外、另外、同时、以及、“；”
+ 句式相同或相近
+ 按照时间顺序展开
找中心句重点时，句与句之间无明显其他类型关联词（转折、因果、对策等）时，可考虑并列 

2、错误选项特征：
+ 表述片面
+ 偷换逻辑

3、正确选项特征
+ 两方面情况：和、及、与、同（罗列型）
+ 更多种情况：许多、一些、不同、各种、一系列（概括型）

## 间接确定重点

中心句不好确定，将分述句去掉，剩下的往往是重点
1、分述句特征
+ 比如、例如、。。就是例证，等例子表述
+ 数据资料
+ 多角度论述
+ 引入铺垫
