
#### 一、求基期，四种题型

1、求基期：代入、直除、假设分配

2、间隔基期： r = r1 + r2 + r1 * r2

3、基期的和差：分别求出基期

4、已知变化量与变化值，求基期


#### 二、求现期

1、假设增量求后期：求出 X，根据“B＝A＋nX”列不等式即可；

2、假设增速求后期

3、按照实际增长率求现期；根据名义增长率求基期，再根据实际增长率求现期 


### 三、求增量

1、求一般增长量

2、求两期增长量倍数或比值

3、各部分增量等于总增量

【注意】
无论是假设分配还是分数法时，将百分率化成好算的百分值进行估算时，求估算方向与实际结果方向

正数情况时：
百分率变小，得到的估算结果也是偏小
变大，则是结果偏大

负数时：
将百分数的绝对值变小，得到的估算结果也是偏小


### 四、求增长率

1、求一般增长率：直接套用公式“R＝X/A”即可

2、求间隔增长率：已知今年较去年增长R1，去年较前年增长R2，则今年较前年增长“R1＋R2 +R1R2”；

间隔增长率的逆运用：已知总的，知道其中部分的一个，求其中部分的另一个
+ 要求的其中部分为正数的情况：得到的结果要额外减去一个R1R2，所以实际结果比求出的偏小
+ 为负数的情况：绝对值比求出的结果偏小

3、间隔倍数：倍数=增长率+1

4、比值增长率工时 = （R1 - R2）/ (1 + R2)
R1：被除数（分子）
R2：除数（分母）

【题型识别】：A = B/C，增长率（要求的结果是两个值之比），且直接/间接给了除数与被除数的的增长率。


5、乘积增长率
【题型识别】：符合表达式 A＝B×C，求 A 的增长，直接/间接给了两个成熟的增长率，求他们乘积的增长率。还有给出整体和占比，求部分时也可使用，部分＝整体×占比
公式： R = R1 + R2 + R1 × R2
