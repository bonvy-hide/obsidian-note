#### 4、市值与业绩表

通过问财提示词模板得到
```
请为【公司名】生成可下载的Excel：近十年每季度最后一个交易日的A股不复权收盘价、季度末总股本(万股)、按“收盘价×总股本股÷1亿”计算的总市值(亿元)，以及按累计财报倒算的单季度营业总收入(亿元)。未披露营收不生成，不要估算；Excel需包含数据表，数据表的列为“序号、财务期间、不复权收盘价(元)、总股本(万股)、总市值(亿元)、财报报告期、单季度营业总收入(亿元)”，并给出下载链接。
```

提示词V2
```text
请为【[公司名]】生成一个可下载的Excel文件，主题为“近十年周度收盘价、总股本、总市值及单季度营业总收入”。 一、股票范围 1. 仅取该公司A股主上市地股票，优先使用A股股票代码对应的证券。 2. 若存在多只A股上市主体或历史更名/代码变更，请优先选择当前主上市主体，并在Excel“口径说明”页中注明股票代码、简称变更或合并处理规则。 3. 若无法确认唯一A股标的，请先列出候选标的及代码，要求我确认后再生成。 二、时间范围 1. 时间区间为“截至当前日往前10年”。 2. 若当前日期为YYYY-MM-DD，则起始日期为10年前的对应日期；若该日为非交易日，则从之后第一个交易日开始。 3. 结束日期为当前可获取的最新交易日，若当前为周末或节假日，则取最近一个交易日。 三、数据内容 Excel主表需包含以下字段： 序号、财务期间、不复权收盘价(元)、总股本(万股)、总市值(亿元)、财报报告期、单季度营业总收入(亿元) 处理规则如下： 1. 财务期间 - 取该区间内每个自然周最后一个交易日的日期。 - “财务期间”格式统一为 YYYY-MM-DD。 - 每周只保留一行，即该自然周最后一个可得交易日。 2. 不复权收盘价 - 取A股“不复权收盘价”。 - 若数据源字段名称不同，请优先选择“收盘价:不复权”“收盘价不复权”“不复权收盘价”等明确字段。 - 禁止使用前复权、后复权、收盘价估算值或盘中价格。 3. 总股本 - 取对应周末或最近可得“总股本”，单位换算为万股。 - 若某周没有新增股本数据，则使用截至该日最近一次已披露的总股本数据向前填充。 - 总股本单位必须为“万股”，并在Excel中保留适当小数位。 4. 总市值 - 按以下公式计算： 总市值(亿元) = 不复权收盘价(元) × 总股本(股) ÷ 1亿 - 注意：总股本字段若原始单位为股，请先换算；若原始单位为万股，则公式应调整为： 总市值(亿元) = 不复权收盘价(元) × 总股本(万股) ÷ 10000 - 请在Excel中使用公式列生成，不要手工填写。 5. 财报报告期 - 填写截至该财务期间已披露的最新财报报告期。 - 财报报告期格式统一为：YYYYQn 或 YYYY中报 / YYYY年报。 - 若某周尚未披露新的财报，则沿用最近一期已披露财报报告期。 6. 单季度营业总收入 - 仅使用公司已披露的累计营业总收入，按累计财报倒算单季度营业总收入。 - 不使用研报预测、机构一致预期、估算值、模型推演值或新闻估算值。 - 若累计营业总收入未披露或为空，则单季度营业总收入不填写，不得估算。 - 倒算规则如下： 2026Q1单季营收 = 2026年一季报累计营业总收入 2026Q2单季营收 = 2026年中报累计营业总收入 - 2026年一季报累计营业总收入 2026Q3单季营收 = 2026年三季报累计营业总收入 - 2026年中报累计营业总收入 2026Q4单季营收 = 2026年年报累计营业总收入 - 2026年三季报累计营业总收入 其他年度同理。 - 若公司财年与自然季度不一致，请在“口径说明”页中说明调整方式；若无法可靠按自然季度匹配，则保留空值。 7. 单季度营收仅在每季度最后一周填写 - “单季度营业总收入(亿元)”列只需要在每个自然季度的最后一周对应行填写。 - 非季度最后一周的记录，该列留空。 - 季度最后一周按自然季度划分： Q1：1月1日至3月31日所在周； Q2：4月1日至6月30日所在周； Q3：7月1日至9月30日所在周； Q4：10月1日至12月31日所在周。 - 若季度最后一个交易日所在周之后尚未披露对应财报，则该行单季度营业总收入留空。 四、Excel格式要求 1. 文件命名为： 【[公司名]_近十年周度收盘价总股本总市值及单季度营收.xlsx】 2. 工作表1名称为“周度数据”，主表列顺序必须为： 序号、财务期间、不复权收盘价(元)、总股本(万股)、总市值(亿元)、财报报告期、单季度营业总收入(亿元) 3. 工作表2名称为“口径说明”，需包含以下内容： - 股票代码与简称； - 数据区间起止日期； - 收盘价字段名称及是否不复权； - 总股本字段名称及单位换算方式； - 总市值计算公式； - 单季度营收倒算公式； - 未披露营收处理方式； - 季度最后一周识别规则； - 若存在简称变更、代码变更、股本变动、数据缺失或口径调整，请逐项说明。 4. 数据格式要求： - “财务期间”为日期格式； - “不复权收盘价(元)”保留2位小数； - “总股本(万股)”保留2位小数； - “总市值(亿元)”保留2位小数； - “单季度营业总收入(亿元)”保留2位小数； - 所有数值列不得以文本格式存储。 5. 请在Excel中添加数据验证或筛选功能，便于查看和筛选财报报告期、季度营收填写行。 6. 请额外生成一个“季度营收填写索引表”工作表，列名为： 财报报告期、对应财务期间、累计营业总收入1、累计营业总收入2、单季度营业总收入、数据来源报告期 用于说明每个已填写单季度营收对应的累计财报和计算过程。 五、输出要求 1. 请直接生成可下载的Excel文件，并给出下载链接。 2. 若关键数据缺失，例如无法取得不复权收盘价、总股本或累计营业总收入，请不要估算，保留空值并在“口径说明”页注明缺失字段和原因。 3. 若数据源中存在同名公司、港股/美股/A股混淆，请先确认A股代码后再生成。 4. 最终回答中请说明：总行数、已填写单季度营收的行数、未填写单季度营收的主要原因、最近一期财报报告期。
```

提示词模板-V3
```text
请按固定模板为【公司名】生成可下载Excel：提取A股近十年每个自然周最后一个交易日的“不复权收盘价、总股本、总市值”，并基于已披露累计营业总收入倒算单季度营业总收入。总市值按“收盘价×总股本股÷1亿”计算；单季度营收仅在每季度最后一周填写，未披露不估算。Excel列名为：序号、财务期间、不复权收盘价(元)、总股本(万股)、总市值(亿元)、财报报告期、单季度营业总收入(亿元)。同时附上口径说明页和季度营收计算索引表，并给出下载链接。
```
