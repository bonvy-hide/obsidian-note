## 资产负债表

资产负债表就是给公司当时的资产情况拍了一张快照
#### 一、所有者权益（股东权益）：
==1、从外面拿进来的钱==
+ 股本：股东在公司中所占的权益
+ 资本公积：企业收到投资者超出其所在注册资本中所占份额，以及直接计入股东权益的利得与损失
==2、从里面剩下的钱==
+ 盈余公积：企业按照法律规定从净利润中提取的各种累计资金
+ 未分配利润：净利润-盈余公积。企业未作分配的利润，
+ 减：库存股(元)：会计准则需要写成减（计算时把该科目做减法运算），企业不能自己拥有自己，所以放在股东权益里不能计入当期利润表，公司回购的股票付出的金额
+ 其他综合收益：资产/负债的公允价值变动，会计准则不允许将其放在当期利润表里

#### 二、资产

+ 无形资产：自研的技术如何不申请专利，不能计入无形资产中，只有专利金额和外购的技术计入无形资产


## 利润表

利润表是一段时间的经营最终赚到的钱
#### 一、营业总成本
+ 营业成本：存货中卖出的部分（不再属于公司）
	+ 财务的艺术：存货增加，销售收入不变，会导致毛利率上升，因为结算时会将多生产的产品的固定成本均摊到更多的产成品上，导致同样销量的情况下营业成本减少，毛利率上升。
	  反直觉之：仅仅扩大产量而不扩大销量，可以增加毛利润。见 《一本书读懂财报》P79
+ 营业税金及附加（或者叫税金及附加）
+ 销售费用（原名营业费用）

## 资产表与利润表映射

- **费用化：** 把钱当作"消耗品"，在花钱的当期一次性计入损益表，直接减少当期利润。
- **资本化：** 把钱当作"投资品"，先计入资产负债表成为一项资产，再在未来多个期间通过折旧或摊销逐步转化为费用。



## 现金流量表

现金流量表向我们展示了资产负债表中的货币资金增加变化的原因
自由现金流FCFF（又叫企业自由现金流，简化版计算公式）= 经营现金流 - 资本开支
+ FCFF > 净利润：持续造血
+ 看长期趋势，若长期为负，成长型企业在扩张烧钱；成熟型企业是否造血能力存在问题
	+ 波动剧烈：可能是周期行业
	+ 逐年下滑：业务模式可能在变差



## 财报实战

#### 一、分析方法

1、同型分析：分析各个科目在总金额的占比
2、趋势分析：与自己的过去对比
3、比较分析：行业平均水平对比

#### 二、偿债能力

存货周转率 = 营业成本 / 存货

流动比率 = 流动资产 / 流动负债。   将资产转为现金还债，自然是越大越好，越大不就代表偿债能力越强吗。

速动比率 = （流动资产 - 存货） / 流动负债。  速动资产越大越好，存货、一年内到期的非流动资产等往往一时无法转换为现金

国内一般通过借新债还旧债，算比率时可以用：
流动比率 = 流动资产 / （流动负债 - 短期借款）

资产负债率 = 总负债/总资产：区分公司是重资产还是轻资产类型，反映了债权人向企业提供贷款的风险程度，也反映了企业举债经营的能力

总资产 = 负债 + 股东权益
总资产报酬率（ROA）| 总资产利润率 = 净利润/总资产

净资产收益率（ROE）= 净利润/股东权益


#### 三、影响财务的因素

外部环境、企业战略定位、企业战略执行能力
+ 战略定位
	+ 成本领先战略：通过降低成本，以低于竞争对手的售价来抢占市场。体现在毛利率低高周转，薄利多销
	+ 差异化战略：体现在高毛利低周转率
+ 战略执行：假如没有做到战略定位，则说明战略执行不行

五力分析模型：
+ 供应商的议价能力
+ 购买者的议价能力
+ 潜在竞争者进入的能力
+ 替代品的替代能力
+ 行业内竞争者现在的竞争能力

投资资本回报率（ROIC） =  税后营业净利润 /  投资资本
税后营业净利润 = 净利润 + 有息负债利息
注意：由于净利润计算是先减去利息，然后再减去税额，假如减去有息负债的利息后小于0则无需交税
投资资本（IC） = 有息负债 + 股东权益
+ 用来描述股东与债权人的综合投资回报

超额收益（ER）= ROIC - 投资资本成本
+ 用来描述ROIC是否及格，>0 才算及格，反之不行、

==经济利润（EP或EVA）= （ROIC - WACC）* IC==
+ 从税后营业净利润中扣除包括股权和债务的全部投入资本成本后的所得，是这家公司超过行业平均水平，真正为股东赚到的钱

资本成本（COC）= 企业为筹集和使用资金而付出的代价

加权平均资本成本（WACC），又叫==投资资本成本== = 有息负债 / 投资资本 * 债务资本成本 * （1 - 企业所得税税率）+ （股东权益 / 投资资本）* 权益资本成本
+ 债务资本成本：贷款利率
+ 权益资本成本：行业平均盈利水平
+ 税后实际利率 = 名义利率 * （1 - 税率）

==结论：所以当一家公司净利润 > 0，但经济利润 < 0，一般说明这不是一家赚钱的公司==

权益乘数（EM）= 资产总额 / 股东权益总额 = 1/（1-资产负债率）
+ 资产总额 = 股东权益总额 + 负债总额
+ ROE = ROA * EM

#### 四、公司的具体分析
1、经营现金流为负：初创公司或衰退阶段
净利润 - 现金净流量 = 资产负债表上除现金外的其他资产和负债的变化值

2、净现比 = 经营活动现金流 / 净利润
看连续三年：优秀企业在1到1.2以上，而一家企业常年低于0.7，甚至连续三年小于0.5则过于危险，这样说明利润常年存在应收账款中

3、应收账款增速、存货增速与营业收入的剪刀差
+ 应收账款增速、存货的增速应与营业收入的增速差不多，应收与存货增速比营业收入差距过大说明企业可能议价能力减弱，只能通过放款信用账期留住客户或产品滞销，还有存货减值风险

4、自由现金流FCC：起码不能常年为负吧

5、流动比率与速动比率：起码不能连短期偿债都无法做到吧

可先去行业研究资料里找到行业的一个状态，再针对个股进行研究

不同的风险优先看不同的表：
竞争激烈的行业下的公司可侧重于看现金流量表
经营风险小的行业的公司可侧重于看利润表

警惕：
+ 存货与应收款增加
+ 毛利率降低
+ 存贷双高：货币与借款双高
