### 一、六种公司类型
+ 缓慢增长型：你买入的目的应该是持股收息
+ 稳定增长型：是否近几年与未来几年保持相同的增长，评估未来是否不再维持增长态势
+ 快速增长型：公司的产品是否供不应求，作者认为维持25%的增长就算快速增长型
+ 周期型：着重观察存货变化与供需变化
+ 困境反转型：是否进行业务重整、降本增效、资产是否能覆盖负债而不至于破产
+ 隐蔽资产型：典型的持有某家公司的股权，该股权评估下来甚至超过本家公司

投资经验：
+ PEG：一家公司的股票如果定价合理，市盈率与收益增长率相等。比如PE=15，该公司的每年（需要看多年来的数据，而不是单一年）收益增长率为15%是合理的，每年收益增长率在20%，PE却只有10，可以考虑是否被低估了

+ 溢价回收率 = （股价 - 每股净资产）/ 每股收益
	+ 不能用来计算破净股、亏损股，该指标为负数没有意义
	+ 每股收益过低导致数值无限大也意义不大
	+ skill第22项

+ 自由现金流
	+ 更加青睐于不需要更多资本开支，而产生同等自由现金流的公司。长期高自由现金流说明在同样的时间能给股东挣更多钱

+ 存货
	+ 存货的增长速度要慢于销售的增长速度，否则又库存积压、存货减值的风险
